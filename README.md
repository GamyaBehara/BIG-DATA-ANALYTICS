# 💼 Employee Attrition Analysis  
### 🧩 Big Data Analytics Project  

This project analyzes **employee attrition** using the **IBM HR Analytics Dataset** to identify key factors that lead to employees leaving an organization.  
The goal is to uncover patterns behind attrition and provide insights to help HR teams improve **retention, satisfaction,** and **workforce stability.**

---

## 🔹 What Does It Do?

- Uses **PySpark** for large-scale data processing and analysis  
- Explores how factors like **age, department, salary, overtime,** and **promotions** influence attrition  
- Visualizes key trends using **bar graphs, pie charts,** and **line plots**  
- Derives **actionable insights** for better workforce management  

---

## 🛠️ Tech Stack

- **Apache Spark (PySpark)**  
- **Python**  
- **Pandas**, **Matplotlib**, **Seaborn**  
- **Jupyter Notebook**  

---

## 📊 Dataset Overview

- **Source:** IBM HR Analytics Employee Attrition Dataset (Kaggle)  
- **Records:** 1,470 employees  
- **Target Variable:** Attrition (Yes/No)  
- **Attributes:** Age, Department, JobRole, Salary, OverTime, JobSatisfaction, and more

## 📈 Key Insights

- Younger employees and those in **Sales** show higher attrition  
- **OverTime** and **low job satisfaction** strongly correlate with turnover  
- **Low salary** and **fewer promotions** increase attrition risk
